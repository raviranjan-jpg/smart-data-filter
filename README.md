# Smart Data Filter

A Streamlit app for uploading Excel/CSV files, selecting columns, filtering rows, removing duplicates, selecting a row range, and exporting Excel/CSV.

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Community Cloud
1. Create a GitHub repository (for example `smart-data-filter`).
2. Upload `app.py` and `requirements.txt` to the repository root.
3. In Streamlit Community Cloud choose that repository.
4. Branch: `main`
5. Main file path: `app.py`
